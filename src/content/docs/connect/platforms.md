---
title: Πλατφόρμες
description: Ποιες πλατφόρμες ηλεκτρονικού εμπορίου μπορούν να στείλουν προσκλήσεις στο Reviewit.
---

Για το WooCommerce υπάρχει έτοιμο πρόσθετο. Για τα υπόλοιπα το Reviewit δεν χρειάζεται πρόσθετο: αρκεί ένα αίτημα HTTP που στέλνει το email, το όνομα και τον αριθμό παραγγελίας. Οτιδήποτε μπορεί να στείλει ένα τέτοιο αίτημα με κεφαλίδα `Authorization` μπορεί να στείλει προσκλήσεις.

## Τι ισχύει σήμερα {#available-now}

| Πλατφόρμα | Πώς |
|---|---|
| **WooCommerce** | Εγκαταστήστε το πρόσθετο [Reviewit Review Invitations for WooCommerce](https://wordpress.org/plugins/reviewit-invitations/) από το WordPress.org και ενεργοποιήστε το. [Δημιουργήστε ένα κλειδί](/connect/get-started/) στη σελίδα «Η επιχείρησή μου» και επικολλήστε το στο **WooCommerce → Reviewit**. Η πρόσκληση στέλνεται όταν μια παραγγελία γίνει «Ολοκληρωμένη». |
| **Οποιοδήποτε κατάστημα με δικό του κώδικα** (OpenCart, PrestaShop, δικό σας) | Καλέστε το API από τον server σας. Δείτε τα [παραδείγματα κώδικα](/connect/code-samples/). |
| **Όποιος δεν έχει κατάστημα ή προγραμματιστή** | [Φόρμα ή αρχείο CSV](/business/send-csv/) στη σελίδα «Η επιχείρησή μου». |
