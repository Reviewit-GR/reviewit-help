# Security

This repository is the public help center of Reviewit.gr: pages, a static site and its build scripts. It has no server, no database
and no secrets.

If you find a security problem (in the site, in its build or workflows, or something private that was published here by mistake, such
as a key or a customer's details), please **do not open a public issue**. Write to [help@reviewit.gr](mailto:help@reviewit.gr), or use
GitHub's private vulnerability reporting (the «Report a vulnerability» button on the Security tab). We will answer within a few
working days.

Problems with Reviewit.gr itself or with your account are not handled here: write to help@reviewit.gr.
